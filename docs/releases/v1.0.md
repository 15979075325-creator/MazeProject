# MazeProject v1.0

首个稳定版本，完成迷宫生成、编辑、求解、可视化、文件读写和自动测试的完整流程。

## 主要功能

- DFS 递归回溯生成完美迷宫。
- 支持 3～51 的自定义奇数行列尺寸。
- 支持随机种子；相同尺寸和种子可复现同一迷宫。
- BFS、Dijkstra 和 A* 三种最短路径算法。
- 三算法路径长度和运行时间比较。
- 坐标编辑与 `W/A/S/D`、方向键键盘编辑。
- 自定义起点 `S` 和终点 `E`。
- 路径逐格动画。
- 文本文件保存和读取，保留空格及起终点。
- Windows `build.bat`、`test.bat` 一键运行。
- GitHub Actions 自动执行 Linux 编译和测试。

## 质量验证

- 求解器测试：直线、转弯、无解、同一点和非法输入。
- 项目测试：生成器连通性、重新生成、固定种子、Maze 边界和文件读写。
- BFS、Dijkstra 和 A* 在无权迷宫中的最短路径长度一致。
- Windows 本地编译和测试通过。
- GitHub Actions 跨平台构建和测试通过。

## 使用方法

1. 安装支持 C++17 的 `g++` 并加入 `PATH`。
2. 双击 `build.bat` 编译和运行。
3. 双击 `test.bat` 运行全部测试。

菜单和详细操作见项目根目录的 `README.md`。
